## About the Repository

This repository contains the **Computer Graphics and Multimedia Lab** programs, practical assignments, and lab activities completed as part of the **Computer Graphics Lab** course.

It covers fundamental computer graphics concepts, including graphics primitives, line and circle drawing algorithms, 2D transformations, polygon operations, clipping, and other graphical techniques.
