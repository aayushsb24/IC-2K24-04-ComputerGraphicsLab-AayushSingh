## About the DDA Algorithm

The **Digital Differential Analyzer (DDA)** is a line-drawing algorithm used in computer graphics to draw a straight line between two given endpoints.

It calculates intermediate points between the starting and ending coordinates using incremental values of X and Y.

### Algorithm Steps

1. Accept the starting point `(x1, y1)` and ending point `(x2, y2)` from the user.
2. Calculate the differences:

       dx = x2 - x1
       dy = y2 - y1

3. Calculate the number of steps:

       steps = max(abs(dx), abs(dy))

4. Calculate the X and Y increments:

       x_increment = dx / steps
       y_increment = dy / steps

5. Initialize the current coordinates with the starting point.
6. Plot each pixel using `putpixel()` after rounding the coordinates.
7. Increment X and Y values until the line is completed.

**Special Case:** If both endpoints are identical, the program plots a single pixel instead of performing the incremental calculations.
